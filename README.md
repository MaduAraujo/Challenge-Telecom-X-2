# Projeto de Predição de Churn: Da Extração ao Machine Learning

Este projeto tem como objetivo analisar o comportamento dos clientes de uma empresa e desenvolver um modelo de Machine Learning capaz de prever o **Churn Rate** (Taxa de Evasão). 
A identificação precoce de clientes com potencial de cancelamento permite que a empresa tome ações preventivas e melhore a retenção.

## Visão Geral do Projeto

O projeto foi dividido em quatro etapas principais, distribuídas ao longo de três semanas de desenvolvimento, cobrindo todo o ciclo de vida de um projeto de dados (ETL, EDA e Modelagem).

## Cronograma de Desenvolvimento

### Semana 1: ETL (Extração, Transformação e Carga)

* **Extração:** Coleta de dados brutos em formato **JSON** e importação para o ambiente Python.
* **Transformação:** Limpeza dos dados, tratamento de valores ausentes, conversão de tipos de variáveis e normalização.
* **Carga:** Exportação dos dados limpos e estruturados para o formato **CSV**.

### Semana 2: Análise Exploratória de Dados (EDA)

* **Visualização:** Criação de gráficos para identificar correlações entre variáveis demográficas, serviços contratados e o Churn.
* **Geração de Insights:** Descrição detalhada de hipóteses e conclusões extraídas dos dados.
* **Análise da Target:** Estudo profundo da variável alvo (`Churn`), identificando o perfil do cliente que evade.

### Semana 3: Machine Learning

* **Tratamento de Dados:** Aplicação de técnicas de **balanceamento da variável target** para evitar vieses no modelo.
* **Modelagem:** Implementação de 5 modelos para comparação de performance.
* **Tuning:** Escolha do melhor algoritmo e otimização de hiperparâmetros para maximizar métricas.

## Tecnologias Utilizadas

* **Linguagem:** Python
* **Manipulação e Limpeza de Dados:** Pandas, NumPy
* **Visualização:** Plotly, Seaborn
* **Machine Learning:** Scikit-learn
* **Processamento de Dados Desbalanceados:** Imbalanced-learn
